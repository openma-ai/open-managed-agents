**Open Managed Agents (openma)** is the session, sandbox, vault, and recovery
platform. **OpenMatter** is a separate, embeddable TypeScript framework for
durable agent **Loops** in work systems (Slack, GitHub, Linear, and others).
This page exists so people searching openma docs for **DeepSeek Harness /
Super-agent / OpenMatter / coordinator-worker** find the right repo and the
short argument — without pasting the long Chinese article here.

## What OpenMatter adds next to openma

openma's [Harness](/concepts/#harness) is the agent loop that decides what the
model does next inside a session. OpenMatter sits on the *work* side: it
accepts platform events, builds authorized context, chooses WorkThread and
Session routing, optionally runs a coordinator with workers, and commits one
terminal Reaction per accepted event. A replaceable **AgentDriver** connects
those Sessions and Turns to ACP, managed runtimes, in-process SDKs, or custom
agents — including harnesses that also run on openma.

The design point, shared with the OpenMatter README: the four Super-agent-style
decisions (routing/session continuity, whether to wake, mid-Turn interruption,
and how replies reach the user) live **outside** the agent, so the harness
stays swappable.

Comparison context already used in the long article — not product claims that
OpenMatter replaces them — includes Claude Tag, Linear Agent Session, and
Claude Projects, alongside DeepSeek Harness's Super-agent design discussion.
